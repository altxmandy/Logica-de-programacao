Aula 1

Sobre a linguagem C

  • É uma linguagem de programação de propósito geral
  • Foi desenvolvida por Dennis Ritchie entre 1969 e 1973 nos laboratórios Bell
  • É uma linguagem de baixo nível, mas com recursos de alto nível
  • É uma linguagem compilada
  • É uma linguagem estruturada
  • processador -> traduz o código fonte para código de máquina
  • diagrama de blocos -> representação gráfica de um algoritmo
  • algoritmo -> conjunto de instruções para resolver um problema
  • case sensitive -> diferencia maiúsculas de minúsculas

Variáveis

Uma variável é um espaço na memória do computador que armazena um valor.

Tipos de variáveis

  • int -> armazena números inteiros
    Ex: -1, 0, 1, 2, 3, ...
    OBS: o tamanho de um int geralmente é de 4 bytes (32 bits).
  • float -> armazena números reais
    Ex: -1.5, 0.0, 1.5, 2.5, 3.5, ...
    OBS: o tamanho de um float geralmente é de 4 bytes (32 bits).
  • char -> armazena caracteres
    Ex: 'a', 'b', 'c', ...
    OBS: o tamanho de um char geralmente é de 1 byte (8 bits).
  • double -> armazena números reais com maior precisão
    Ex: -1.5, 0.0, 1.5, 2.5, 3.5, ...
    OBS: o tamanho de um double geralmente é de 8 bytes (64 bits).

Alguns comandos falados aula 1

  • #include -> diretiva de pré-processamento para incluir bibliotecas
  • stdio.h -> biblioteca padrão de entrada e saída
  • int main() -> função principal que retorna um inteiro
  • & -> operador de endereço, usado para passar o endereço da variável para a função scanf
  • \t -> tabulação horizontal
  • int -> inteiro
  • printf -> função de saída (exibir no terminal)
  • scanf -> função de entrada (receber do terminal)
  • %d -> especificador de formato para inteiros
  • endereço de memória -> local na memória onde a variável está armazenada
  • pointer -> variável que armazena o endereço de memória de outra variável
  • return -> retorna um valor da função para o chamador

Sistema de Numeração

  • Decimal -> base 10 (0-9)

    Ex: 123456

  • Binário -> base 2 (0 e 1)

    Ex: 123456 -> 11110000001000000

  • Octal -> base 8 (0-7)

    Ex: 123456 -> 361100

  • Hexadecimal -> base 16 (0-9, A-F)

    Ex: 123456 -> 1E240

  • OBS: endereço com o começo 0x é um valor hexadecimal, que é uma representação de números em base 16.

Bytes

  • 1 byte = 8 bits
  • 1 bit = 0 ou 1
  • 1 byte pode representar 256 valores diferentes (2^8)
  • Ex: 00000000 -> 0, 00000001 -> 1, 00000010 -> 2, ..., 11111111 -> 255

Alguns comandos falados aula 2

  • %d -> especificador de formato para inteiros
  • %f -> especificador de formato para float
  • %.2f -> especificador de formato para float com 2 casas decimais
  • %c -> especificador de formato para char
  • %hu -> especificador de formato para unsigned short int
  • %u -> especificador de formato para unsigned int
  • %hd -> especificador de formato para short int
  • %ld -> especificador de formato para long int
  • %lld -> especificador de formato para long long int
  • %lf -> especificador de formato para double

Aula 3

Sequências de Escape

  • \n -> Nova linha

    Ex: "Olá\nMundo" --> "Olá
    Mundo"

  • \t -> Tabulação

    Ex: "Nome:\tAmanda" --> "Nome: Amanda"

  • \b -> Backspace

    Ex: "Olá\bMundo" --> "OlMundo"

  • \r -> Retorno de carro

    Ex: "Olá\rMundo" --> "Mundo"

  • \a -> Alerta sonoro

    Ex: "Olá\a" --> "Olá" (com som de alerta)

  • \\ -> Barra invertida

    Ex: "C:\\Users\\Amanda" --> "C:\Users\Amanda"

  • \" -> Aspa dupla

    Ex: "Ele disse \"Olá!\"" --> "Ele disse \"Olá!\""

  • \\' -> Aspa simples

    Ex: "Ele disse \'Olá!\'" --> "Ele disse 'Olá!'"

Operadores aritméticos

  • + -> Adição
  • - -> Subtração
  • * -> Multiplicação
  • / -> Divisão
  • % -> Módulo (resto da divisão)
